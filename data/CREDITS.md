## Map data

`data/roads.json`: © OpenStreetMap contributors, Open Database License (ODbL 1.0), https://www.openstreetmap.org/copyright. Fetched through the Overpass API by `scripts/fetch-roads.mjs`.

Landmark coordinates come from Wikidata, Wikipedia and OSM Nominatim.

`data/routes.json`: route geometry © OpenStreetMap contributors, ODbL 1.0. We built it by `scripts/fetch-routes.mjs` with the OSRM routing engine (http://project-osrm.org/). Walking legs come from the FOSSGIS OSRM server (https://routing.openstreetmap.de, profile `routed-foot`). Bus and taxi legs come from the OSRM demo server (https://router.project-osrm.org, profile `driving`). The funicular track of the Elevador do Bom Jesus comes from OSM ways 26307689 and 772942621.

## Геоданные

`data/footprints.json`, `data/buildings.json` and the `osm` field in `data/landmarks.json`: © OpenStreetMap contributors, Open Database License (ODbL 1.0), https://www.openstreetmap.org/copyright. We fetched them through the Overpass API with `scripts/fetch-footprints.mjs` and `scripts/fetch-buildings.mjs`. We simplified the building outlines and dropped their holes. Where OSM has no height, the height is an estimate or a published figure; `height_source` names it. Wikidata (CC0, https://www.wikidata.org) helped us check which OSM object belongs to which landmark.

`data/terrain.json`: elevation from EU-DEM v1.1 (25 m), © European Union, Copernicus Land Monitoring Service, produced with funding by the European Union (https://land.copernicus.eu/). We read it through the OpenTopoData API (https://www.opentopodata.org) with `scripts/fetch-terrain.mjs`. The script falls back to SRTM 30 m (NASA/USGS, public domain) or Open-Elevation only when EU-DEM fails; the file's `source` field names the dataset it used.

## Landmark dimensions

`data/dimensions.json` holds real-world sizes for all the landmarks, so the models can be built at 1:1 metres. Each number names its source in `sources[]`. A published number carries the URL and the quoted value. Few heights are published, so many numbers are estimates: we measured them from the OSM outlines above, the EU-DEM terrain, and the Wikimedia Commons photos listed in this file, and each estimate states its reasoning. `node scripts/check-dimensions.mjs` validates the file.
